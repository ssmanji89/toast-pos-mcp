<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| lifecycle caller → polling engine | A caller receives a finite state machine, not direct fetch access or a generic retry loop. |
| Toast job status → completeness envelope | Pending, invalid-or-expired, conflict, malformed, failed, and G05-blocked responses remain explicit non-success states. |
| Analytics identity/location set → limiter state | Rate capacity is isolated by private authority and canonical set for every endpoint/method/time-range turn. |
| runtime → T5-003 | The runtime provides an internal adapter only; T5-003 alone can register MCP presentation. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T5-002-05-01 | Denial of service | lifecycle stages and polling loop | mitigate | Propagate one caller-owned signal through capability/token acquisition, limiter waits, sleeps, and every fetch; abort ends the lifecycle without later turns or result publication. Enforce cancellation-aware local-policy poll and replacement budgets. |
| T5-002-05-02 | Information disclosure | failures and result state | mitigate | Use body-free status handling; retain no raw errors, tokens, result bodies, or guest-linked fields. |
| T5-002-05-03 | Tampering | limiter identity key | mitigate | Key private state by Analytics identity, closed operation, method, time range, and canonical selected set; mutate each dimension in tests. |
| T5-002-05-04 | Elevation of privilege | unresolved vendor contracts | mitigate | Treat G01-G05 as open gates and prevent models or claims for unproven routes, options, identifiers, fields, and top-level shapes. |
| T5-002-05-05 | Elevation of privilege | runtime composition | mitigate | Reuse only Analytics-owned identity/token/access state and retain the no-registration boundary. |
| T5-002-05-SC | Tampering | npm dependency supply chain | mitigate | Candidate validation uses authentic locked dependency restoration and both supported Node runtimes. |
</threat_model>
