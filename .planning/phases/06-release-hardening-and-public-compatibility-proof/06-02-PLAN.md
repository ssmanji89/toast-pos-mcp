<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Repository candidate to npm tarball | npm package rules can omit runtime files or include development material. |
| Tarball to empty consumer | A local install can accidentally use the checkout or a link instead of published artifact bytes. |
| Test-only preload to installed executable | Child-process environment injection must not enter the package or permit outbound access. |
| Local synthetic evidence to public records | Accurate local evidence can be overstated as legal, publication, or live-compatibility authority. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-06-03-01 | Tampering | npm artifact contents | mitigate | Test npm dry-run JSON and real tar paths against an explicit runtime/docs allowlist before installing the tarball. |
| T-06-03-02 | Spoofing | Consumer executable target | mitigate | Spawn only the absolute consumer `node_modules/.bin` path; reject source-path and link-based execution. |
| T-06-03-03 | Information disclosure | Child environment and fixture responses | mitigate | Use allowlisted synthetic process values and invented preload data; reject unmatched fetch routes; do not retain raw stderr or environment values. |
| T-06-03-04 | Elevation of privilege | Analytics tool invocation | mitigate | Call Analytics only with its existing unconfigured denied/incomplete contract; do not add credentials, scope, body parser, or complete-result claim. |
| T-06-03-05 | Repudiation | Evidence and campaign records | mitigate | Record candidate SHA, runtime/npm versions, commands, discovery/test counts, checksum, tar paths, tool list, schema versions, and exact remaining gates. |
| T-06-03-SC | Tampering | Existing npm dependency restoration | accept | No dependency is added or upgraded. Restore only the committed lockfile with `npm ci --no-audit --no-fund`; do not substitute copied caches, hand-built lockfiles, or validation doubles. |
</threat_model>
