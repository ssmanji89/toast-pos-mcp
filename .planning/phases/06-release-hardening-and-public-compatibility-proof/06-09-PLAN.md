<threat_model>

| Threat | Boundary | Mitigation |
| --- | --- | --- |
| Credential disclosure | userConfig to MCP process | Sensitive Claude storage, exact env allowlist, generic launcher errors, no credentials in skill/docs/tests. |
| Supply-chain drift | GitHub source to cached runtime | Explicit plugin version, repository-root source, committed npm lockfile, frozen automatic restore, pinned compiler. |
| Alternate implementation | plugin wrapper to report runtime | Launcher only compiles/imports `src/index.ts`; it contains no tool registration or report formulas. |
| MCP framing corruption | launcher build to stdio | Compiler stdio ignored; wrapper emits only generic stderr; stdout reserved for runtime JSON-RPC. |
| Concurrent first-start race | multiple MCP starts | Atomic build-lock directory, bounded wait, stale-lock recovery, exact output existence check. |
| Permission overreach | install to external Toast service | Disabled by default, explicit consent acknowledgment, Standard-only preview configuration, safety skill. |
| False release claim | local tests to public status | Task 3 real Claude checkpoint; npm, live Toast, brand, signing, and Analytics G01 remain separate. |
